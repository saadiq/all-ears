# Stage result envelopes

One JSON Schema per pipeline stage (`<tool>.v1.schema.json`) defining the `--json` result envelope the stage prints on stdout — the machine-readable contract between the stage binaries and the daemon's session-end chain, specified in [docs/specs/llm-stages.md](../../docs/specs/llm-stages.md#result-envelopes---json). Compatibility rule: additive keys are non-breaking and consumers must ignore unknown keys (the schemas leave `additionalProperties` permissive on purpose); removing or renaming a key bumps the major in the `schema` field (`allears.<tool>/v<major>`), and consumers fail only on a major mismatch. The `.examples.json` fixtures beside each schema are decoded and round-tripped by the Swift suite (`StageEnvelopeFixtureTests`), so a fixture that drifts from the `Codable` types fails the build.
